# Proyecto de Sincronización de Lector-Escritor con Ring Buffer en Qt

Este proyecto es una aplicación práctica de los conceptos de programación concurrente utilizando Qt, específicamente centrada en la implementación y sincronización de un ring buffer para resolver el problema del lector-escritor.

## Objetivos del Proyecto

Los estudiantes trabajarán en parejas para completar este proyecto. Los objetivos son:

1. Entender y aplicar mecanismos de sincronización en un entorno multihilo, con énfasis en la estructura de datos del ring buffer.
2. Practicar la programación en parejas (pair programming) y el uso de Git para la colaboración y control de versiones.

## Tareas a Realizar

### 1. Diagrama de Flujo

Cada pareja debe crear un diagrama de flujo que represente el flujo de ejecución del programa de lector-escritor, incluyendo cómo se gestiona el ring buffer y la lógica de sincronización entre lectores y escritores. Este diagrama debe subirse al repositorio del proyecto:

- Si el diagrama se hace a mano, subir una foto clara del mismo.
- Si se utiliza un programa de diagramas, subir el archivo correspondiente o una captura de pantalla.

### 2. Implementación del Código

El proyecto contiene varios `TODO` que deben ser completados. Por cada `TODO` en el código:

- Añadir la implementación necesaria siguiendo las indicaciones proporcionadas en los comentarios.
- Cada `TODO` completado debe corresponder a un commit en Git. Asegúrense de que la descripción del commit sea clara y refleje los cambios realizados.

### 3. Distribución de Tareas

- Las tareas deben distribuirse equitativamente entre los miembros del grupo. Intenten que cada miembro tenga un número igual (o casi igual) de commits.
- Cada miembro del grupo debe trabajar en su propia rama de Git, siguiendo la nomenclatura `_feature_nombre_alumno`. Por ejemplo, `_feature_juanperez`.
- Practiquen el pair programming: aunque cada uno trabaje en su rama, deben colaborar en las soluciones, discutir las implementaciones y revisar el código del otro.

## Información Complementaria

- La definición detallada del problema del lector-escritor y los detalles adicionales sobre el proyecto están disponibles en el campus virtual.
- Este proyecto se enfoca en la resolución del problema del lector-escritor utilizando específicamente la estructura de datos de un ring buffer para la sincronización entre hilos.

## Reglas de Colaboración

- Antes de comenzar a codificar, dividan los `TODO` y asegúrense de que cada miembro del equipo comprenda su responsabilidad.
- Mantengan una comunicación constante para evitar trabajar en las mismas partes del proyecto simultáneamente.
- Revisen y comenten el código del otro para garantizar que ambos entiendan todas las partes del proyecto.

## Entrega

- Asegúrense de fusionar (merge) todas las ramas de características a la rama principal (main/master) una vez que hayan completado el proyecto.
- Verifiquen que el código final compile y ejecute correctamente antes de la entrega final.
- Incluyan en el repositorio el diagrama de flujo final junto con el código fuente completo.

¡Buena suerte!
